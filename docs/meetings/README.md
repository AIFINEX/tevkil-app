# Meetings

Date-stamped meeting notes. Treat these as the running log of conversations between people (and AI), so anyone joining later can catch up.

## Naming

```
YYYY-MM-DD-<slug>.md
```

Examples:

- `2026-05-04-kickoff.md`
- `2026-05-11-architecture-discussion.md`

## What goes in a notes file

- Date, attendees
- Agenda
- Decisions made (link to RFC if it produced one)
- Action items with owner and due date
- Open questions to follow up

Keep it short. If a topic deserves a deeper write-up, spin off an RFC.
